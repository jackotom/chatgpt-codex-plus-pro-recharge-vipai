## 选择商品时看什么

| 服务方向 | 下单前必须核对 |
| --- | --- |
| ChatGPT Plus / Pro 开通、升级或续费 | 原订阅渠道、当前状态、账号适用条件、目标档位和生效时间 |
| Codex 相关服务 | 交付的是订阅、点数还是活动相关服务；适用账户、有效期与使用范围 |
| Claude 中转 API 额度 | 实际提供服务的平台、接口地址、计费单位、余额有效期及售后条件 |

不要把名称带有 Codex 的商品都理解为官方额度直充；活动资格与点数到账条件须逐项确认。Claude 中转 API 额度属于对应服务渠道，不等同于 Anthropic 官方余额，也不等同于 Claude Pro / Max 会员订阅。

价格、库存、交付方式和处理时间以[商品详情](https://vipai.pro/products)为准。本仓库不统一承诺秒到账、无限使用或无风险。

## 下单与查询

1. 阅读[购前指南](guides/before-purchase.md)，确认服务匹配自己的账号和用途。
2. 在商品页核对规格、交付条件及售后范围，再按站内指引下单。
3. 保存订单号和商品说明，通过[游客订单查询](https://vipai.pro/guest/orders)或登录后的订单页面查看进度。
4. 按[验收清单](guides/order-check-and-support.md)核对结果；有差异时使用网站公布的客服入口。

账号、密码、验证码、API 密钥和完整订单信息请勿提交到公开 GitHub Issue。
