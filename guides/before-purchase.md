# ChatGPT 代充、直充前：账号与渠道检查清单

下单前先写清楚三件事：充到哪个账号、现在是什么订阅、希望得到什么。商品名里都有“充值”，交付内容却可能不同。本指南用于核对购买条件，不保证任何账号或渠道一定适用。

## 1. 先确认目标账号

在自己打开的官方应用或网站里确认目标账号与工作区，避免混淆。

不要把密码、验证码或登录凭据发到公开仓库。购买流程要求敏感授权时，先弄清用途和范围；不清楚就暂停。

## 2. 把已有订阅查清楚

| 要核对的项目 | 建议记录 |
| --- | --- |
| 当前套餐 | 免费、Plus、Pro 或页面显示的其他套餐 |
| 原购买渠道 | 网页、Apple、Google 或其他已确认渠道 |
| 当前状态 | 生效中、已取消续订、已到期，按页面原文记录 |
| 时间 | 页面显示的到期或下一次扣款时间 |
| 本次目标 | 首次开通、续费或升级，以及希望的生效日期 |

“已取消续订”和“当前权益已到期”应分开核对。不要仅凭取消操作就判断自己已经符合新商品条件；以实际订阅页面和所选商品的要求为准。

例如：原来通过手机应用订阅，想买网页渠道续费商品，应先确认能否办理、何时生效，不要假设不同渠道能叠加。

## 3. 看交付内容，不只看“直充”两个字

代充、直充和续费是商家对服务的描述，不能替代具体交付条款。打开[商品详情](https://vipai.pro/products)，逐项确认：

- 交付到现有账号，还是需要兑换、邀请或其他步骤？
- 是否限制账号地区、原订阅渠道、到期状态或活动资格？
- 交付的是订阅时长、某种点数，还是服务商的 API 余额？
- 从付款、受理还是实际开通开始计算时长？
- 预计处理时间、失败处理和售后范围分别是什么？

如果买的是额度，先读[订阅、点数与 API 区别](subscription-credits-api.md)。如果买的是礼品卡或兑换类商品，还要核对兑换地区、有效期及未使用时的处理条件。

## 4. 付款前保留一份确认

保留商品名称、规格、金额、交付条件、售后说明及客服补充记录，供验收时比较。

可直接向客服说明：

> 我想为现有账号办理【开通／续费／升级】。原订阅渠道是【渠道】，目前页面显示【套餐及状态】，希望得到【目标规格】。请确认该商品是否适用、生效时间、需要我完成的步骤，以及无法办理时的处理方式。我不会在公开页面提交账号凭据。
