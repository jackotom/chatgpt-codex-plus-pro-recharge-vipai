# ChatGPT 订阅、Codex 点数与 API 额度：购买前怎样区分

先问“我要在哪个产品里使用”，再比较价格。会员套餐、额外点数和 API 余额的名称相近，但不能仅凭“额度”两个字就认为能互相使用。

## 先按用途分类

| 想做的事 | 要核对的对象 | 下单前问清 |
| --- | --- | --- |
| 使用 ChatGPT 会员功能 | 对应账号的订阅套餐 | 目标套餐、时长、账号条件和交付渠道 |
| 继续使用 Codex | 实际登录方式及用量页面 | 当前用的是 ChatGPT 账号还是 API Key，所购权益适用于哪一种 |
| 为程序调用模型 | 实际 API 服务商与计费账户 | API 地址、支持范围、计费单位、余额归属和有效期 |
| 参加点数或邀请活动 | 对应活动规则及账户资格 | 资格条件、奖励触发条件、适用范围和失效条件 |

这张表是选择方法，不表示 VIPAI 当前出售表中所有产品；实际在售项目看[商品中心](https://vipai.pro/products)。

## ChatGPT 套餐与 Codex 用量

OpenAI 官方说明区分了套餐内用量和额外 credits，并单列使用 API Key 的计费方式。判断自己需要什么，应先查看账号的用量页面，以及 Codex 当前采用的登录方式；不要只看应用名称。[官方计费说明](https://learn.chatgpt.com/docs/pricing)

例如：Codex 提示用量不足，先记录原文和用量页状态，再问所选商品补充哪一种用量，不要仅凭名称下单。

套餐功能、额度和重置时间以官方页面及账号状态为准，本指南不承诺固定调用次数。

## API 额度先看服务商

OpenAI API 有自己的计价表；以 API Key 使用时，应按实际 API 计费账户核对费用。[OpenAI API 官方价格说明](https://developers.openai.com/api/docs/pricing)

如果商品写的是“中转 API”，应确认余额记在哪一家服务商、请求发送到哪个接口、账单由谁提供。VIPAI 的 Claude 中转 API 额度不能据此理解为 Anthropic 官方余额，也不是 Claude Pro / Max 订阅。

例如：给程序配置接口时，先确认服务商和接口类型。同名模型不代表余额通用，核对时也无需公开实际 API 密钥。

## 点数和活动奖励要看条件

看到点数或邀请类商品时，核对以下四项，而不是只比较数字大小：

1. 计入哪个账号或工作区，在哪里能看到记录。
2. 是否有资格限制，是否需要完成指定活动。
3. 点数能用于哪些服务，何时失效。
4. 未满足活动条件或奖励未到账时，商家如何处理。

本指南不承诺任何活动资格、奖励数量或到账结果，也不把邀请相关服务写成官方充值产品。
